редко встречающийся уровень аккуратности для PoC. Баланс вынесен в `src/core/config.ts` целиком.

## Блокеры

### 1. Весь UI замирает, пока фокус на `<select>`

`src/useGameSession.ts:122`

```js
if (document.activeElement instanceof HTMLSelectElement) return
state.value = core.snapshot()
```

Фокус остаётся на селекте после выбора значения, до клика в стороне. Всё это время `state.value`
не обновляется, хотя симуляция в `GameCore` идёт: замирают часы, бодрость, маркеры отрядов, лента,
счётчики склада. Хуже — `publishSnapshot()` вызывается и из `runCommand()`, поэтому результат самой
команды (назначение кота, выдача предмета) не виден: обновляется только локальный `draft` внутри
селекта. И если в этот момент стартует рейд, блокирующий оверлей не появится, хотя `state.speed`
в ядре уже 0.

Лечить надо не на уровне снимка, а точечно: механизм `interacting` в компонентах уже есть —
достаточно заморозить на время взаимодействия только те привязки, которые Vue патчит внутри
открытого селекта (список `<option>` и их `:disabled` от `state.inventory`), а снимок публиковать
всегда.

- `src/components/CatAssignmentSelect.vue:23`, `:48`, `:52`, `:53`
- `src/components/EquipmentSlotSelect.vue:50`, `:54`
- `src/components/SquadStyleSelect.vue:25`, `:29`

Плюс функция `debugEvent`, навешенная на `mousedown` / `click` / `focus` / `pointerdown`.

### 3. Селект не откатывается, если команда отклонена

`src/components/CatAssignmentSelect.vue:44`

`lastEmittedValue` присваивается до `emit`, а `watch` на `props.cat.assignedTo` не срабатывает,
потому что состояние не изменилось. Селект навсегда остаётся на неверном значении, и повторный
выбор того же значения глушится как «duplicate» — то есть отменить нельзя, надо сначала выбрать
что-то третье. Воспроизводится реально (проверено отдельным probe-тестом): спящий кот с бодростью
30 → `canReceiveWorkOrder` возвращает `false`, `assignCat` (`src/core/simulation.ts:668`) возвращает
`false`, а дропдаун показывает «Отряд «Альфа»» без какого-либо объяснения.

Тот же паттерн в `EquipmentSlotSelect` / `SquadStyleSelect`. Заодно: `CatAssignmentSelect` и
`SquadStyleSelect` слушают и `@input`, и `@change`, а `EquipmentSlotSelect` — только `@change`.
Стоит унифицировать.

### 4. Горячие клавиши 1/2/3 снимают паузу под блокирующими оверлеями

`src/useGameSession.ts:200`

`setSpeed` защищён только от `state.incident` (`src/useGameSession.ts:182`). Оверлеи «Девятая
жизнь», финальной сводки и подтверждения сброса ставят `speed = 0` и закрывают топбар (`inset: 0`),
но клавиатура не заблокирована — нажатие «1» продолжает симуляцию за модалкой. Спека требует, чтобы
эти окна были блокирующими.

### 5. Fallback в генераторе миссий может наложить метки

`src/core/simulation.ts:1047`

После 20 неудачных попыток возвращаются фиксированные `generation.fallback` = `{x: 50, y: 20}` без
проверки `minimumSeparation`, тогда как спека прямо запрещает две активные уборки в одной точке.
При цикле потока до 5 миссий это достижимо.

## Расхождения со спекой

- **Экспорт JSON не содержит язык и аудионастройки.** Спека: «Экспортируемый JSON содержит
  `saveVersion`, всё состояние симуляции, seed RNG, выбранный язык и аудионастройки». В
  `SaveEnvelope` (`src/core/simulation.ts:162`) их нет — они живут в отдельных ключах `localStorage`
  (`src/useGameSession.ts:38`), то есть импорт на другой машине их теряет.
- **Автослот пишется раз в секунду безусловно**, включая паузу без изменений
  (`src/useGameSession.ts:145` вызывается из тика каждые 250 мс), вместо «после команд игрока и
  важных доменных событий». Payload — 4964 байта pretty-printed против 2979 минифицированных;
  `JSON.stringify(envelope, null, 2)` для автослота смысла не имеет.
- «Повышенная заметность алертов» у `emergency_dispatch` не реализована — только сокращение 8→5 с.
- Тост показывается только для достижений (`handleEvents`, `src/useGameSession.ts:161`); для
  `incident_started` / `story_started` играет звук без уведомления, хотя спека просит toast для
  важных событий.
- `tr('Закрыть')` (`src/components/OperationsMap.vue:89`) отсутствует в обоих словарях → в
  EN-локали рендерится русский. Плюс мёртвая EN-запись «Любое изменение ставит время на паузу…» от
  старой версии подсказки (текст сейчас противоположный по смыслу) и неиспользуемый `sound.unmute`.

## Мёртвый код и гигиена

- **14 неиспользуемых импортов** в `src/useGameSession.ts:2-31`: все 12 алиасов `*Command`
  (все команды идут через `core.dispatch`), плюс `tick` и `drainEvents`. Проходит `npm run check`,
  потому что в `tsconfig.json` нет `noUnusedLocals` / `noUnusedParameters` — стоит включить.
- `src/core/replaceState.ts` в приложении не используется вообще; единственный его потребитель —
  `src/useGameSession.test.ts`, то есть тест охраняет мёртвый код. Реальный путь замены —
  `GameCore.replaceState` через `structuredClone`.
- Неиспользуемые экспорты `simulation.ts`: `SAVE_FORMAT`, `SAVE_VERSION`, `syncAchievements`,
  `successfulCleanups`, `canReceiveWorkOrder`, `deserializeState` (приложение ходит только через
  `deserializeCurrentSave`). `canEditEquipment` (`src/core/simulation.ts:714`) — заглушка,
  всегда `true`.
- **Три CSS-файла с конфликтующими правилами.** `.cleanup-pin.assigned` в `src/style.css` — серый
  и `opacity:.35`, в `src/missions.css:49` — зелёный и `opacity:1`; работает только за счёт порядка
  импортов в `src/main.ts:3`. `.map-view` определён в `style.css` и переопределён в
  `src/layout-fix.css` — имя файла говорит само за себя, правки стоит внести в основной стиль.
  В `style.css` мёртвые `.cat`, `.cat img`, `.cat select`, `.roster` от прежней разметки;
  `.cat-assignment` в `missions.css:367` не встречается ни в одном шаблоне.
- **~15,4 МБ PNG в репозитории** (`assets/art/*.png`, по 2+ МБ каждый) не импортируются нигде —
  используются только `.webp`.
- **Дублирование констант**, хотя спека требует «все числа в едином конфиге»: база — в
  `src/core/config.ts:96`, в `src/components/OperationsMap.vue:11` и в CSS
  (`.base-pin{top:51%;left:46%}`); смещение времени 09:00 — в `src/App.vue:46` (`9 +`), в
  `src/components/OperationsMap.vue:61` (`540 +`) и в миграции; хардкод `x: 68, y: 36` в
  `src/core/simulation.ts:963`.
- **Нет README, CI, линтера, `wrangler.toml`** — при том что `build` копирует `worker/index.js`
  в `dist/server/`, то есть деплой-конфиг живёт вне репозитория. `AGENTS.md` — одна строка со
  ссылкой на спеку.
- **Диалоги без focus trap и без Escape** — `role="dialog" aria-modal="true"` есть, но фокус не
  перехватывается и закрыть с клавиатуры нельзя.
- **Тесты только SSR-строковые** (`renderToString`), реального DOM нет. Именно поэтому баги 1–3
  прошли: они все про интерактивность нативного `<select>`. Один браузерный тест на «выбрать кота
  в дропдауне → карточка обновилась» закрыл бы весь класс.
